# INFORME DE INGENIERÍA DE SOFTWARE

**Proyecto:** QrPass  
**Tipo:** Prototipo web para el recaudo y validación de pasajes en transporte público  
**Ubicación:** Ibagué, Colombia  
**Fecha:** Octubre 2026  

## Elaborado con base en
Código fuente implementado (`backend/`, `frontend/`), pruebas automatizadas (`backend/tests/`) y documentación existente.

Documentar el ciclo de vida del desarrollo de QrPass desde el análisis, diseño, arquitectura, implementación, pruebas, despliegue y trazabilidad, con el fin de dejar un informe completo, claro y verificable para fines académicos.
